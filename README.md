# fakecallkit

нативное ios-приложение на swiftui и callkit для планирования реалистичных фейковых входящих вызовов с кастомными сценариями, задержкой и голосовыми репликами

## фичи

- **реальный экран звонка ios**: вызов отображается через системный callkit (с нативным системным слайдером, кнопками ответа и рингтоном)
- **голосовые реплики в ушной динамик**: можно записать голос собеседника прямо в приложении, и после поднятия трубки звук пойдет в разговорный динамик (.voiceChat)
- **поддержка action button и быстрых команд**: мгновенный запуск активного сценария через appintents и кнопку действия на iphone 15 pro / 16
- **гибкие таймеры**: задержка 5, 10, 20 или 30 секунд перед входящим вызовом
- **минималистичный темный ui**: интерфейс в строгом матовом графите с тактильным taptic feedback

## структура проекта

- `ScriptModel.swift` — модель сценария звонка (имя абонента, задержка, аудиофайл)
- `CallManager.swift` — менеджер callkit (cxprovider) для вызова системного экрана звонка
- `AudioRecorderService.swift` — сервис записи голоса в .m4a
- `AudioPlayerService.swift` — воспроизведение записанного звука в разговорный динамик
- `TriggerFakeCallIntent.swift` & `FakeCallShortcuts.swift` — интеграция с action button и командами siri
- `ContentView.swift` — главный экран со списком сценариев и быстрым запуском
- `CreateScriptView.swift` — экран создания нового сценария и записи звука

## требования

- ios 17.0+
- xcode 15.0+
- swift 5.9+

## как запустить

1. клонируй репозиторий:
```bash
git clone https://github.com/your-username/FakeCallKit.git
```
2. открой `FakeCallKit.xcodeproj` в xcode
3. выбери симулятор или подключенный iphone
4. нажми `Cmd + R` для сборки и запуска

## как тестировать входящий звонок

1. выбери сценарий и нажми «через 5 сек» (или используй кнопку на корпусе action button)
2. сверни приложение или заблокируй экран iphone
3. через 5 секунд система выведет настоящий экран входящего вызова
4. сними трубку — начнется воспроизведение записанной реплики в разговорный динамик
